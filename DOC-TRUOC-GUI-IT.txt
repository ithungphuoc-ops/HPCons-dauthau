BA VIỆC IT CẦN LÀM
  1. Cài & chạy thử:      npm install   →   npm run build   →   npm start
  2. Khai biến môi trường — gói này CÓ 7 BIẾN MỚI so với lần trước
     (5 biến Cloudflare R2, 1 API Key cho App Tổng, 1 secret báo sự cố).
     File .env.example đã cập nhật đầy đủ kèm giải thích từng biến.
     KHÓA THẬT xin trực tiếp từ Sếp, không gửi qua chat.
  3. Deploy lên subdomain  dauthau.hpcore.vn  (bắt buộc — cookie phiên của
     App Tổng không gửi sang domain khác).

VIỆC HẠ TẦNG MỚI PHÁT SINH TRONG BẢN NÀY (nhờ IT làm giúp)
  • Tạo bucket Cloudflare R2 tên "hpcons-dauthau" + tên miền public cho
    bucket. Ảnh đính kèm nay lưu trên R2, Firestore chỉ giữ metadata.
    Chưa có thì mục "Ảnh báo cáo đã gửi báo giá" báo lỗi khi tải ảnh lên.
  • Mở quyền Firestore cho collection "anhDinhKem" (metadata ảnh).
  • Mở quyền Firestore cho collection "templates" — việc này đã nêu ở gói
    18-08, nhờ IT xác nhận lại đã mở chưa.
  • Sinh một chuỗi ngẫu nhiên cho HPCONS_PORTAL_API_KEY và khai GIỐNG NHAU
    ở cả app này lẫn App Tổng (dùng cho route /api/summary).
  Chi tiết từng việc: xem mục 2 của BAN-GIAO-2026-09-12.md.

DỮ LIỆU CÓ CẦN CHUYỂN ĐỔI KHÔNG?
  KHÔNG. Đợt này thêm 3 trường mới (maNoiBo · vong của phiếu dời hạn ·
  doneDates của lịch lặp) nhưng cả 3 đều TÙY CHỌN, hồ sơ cũ đọc lên không
  đổi nghĩa. Không phải chạy script chuyển dữ liệu, không phải ghi đè gì
  trên Firestore.

GÓI NÀY KHÔNG CÓ (cố ý, vì lý do bảo mật / dung lượng)
  • .env.local và mọi khóa thật (service account Firebase, khóa R2, API Key).

  • Các file Excel dữ liệu thật của Phòng.
